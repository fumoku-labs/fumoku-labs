### 🌱 About Fumoku Labs
**Fumoku Labs** is an indie game studio exploring games as a creative and experimental medium.

We believe games don’t need to fit one formula or genre.  
Each project is an opportunity to try something new — mechanically, visually, or emotionally.

---

### 🎮 What We Make
- Narrative games  
- Experimental mechanics  
- Small to mid-scale projects  
- Story-driven or systems-driven experiences  

Some games may be emotional.  
Some may be simple, weird, or playful.  
What matters is **honesty in creation**.

---

### 🛠 Tools & Technology
- **Game Engine:** Unity  
- **Programming:** C#  
- **Art:** Krita  
- **Audio:** Cakewalk Next  
- **Version Control:** Git & GitHub  

---

### 🚧 Studio Status
Fumoku Labs is currently developed as a **solo indie studio**, with the freedom to evolve and grow over time.
